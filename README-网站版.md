# 🌐 网页版网站（Apple Detection Web）

本项目后端不仅服务微信小程序，本身也直接托管了一个**响应式网页版网站**。打开网站即可上传图片、实时检测苹果/水果并查看标注图与统计，**不需要微信开发者工具，手机浏览器也能用**。

网站与小程序共用同一套后端接口（`/api/detect`），因此后端链路验证一次即可两处通用。

## 功能

- 拖拽 / 点击 / 手机拍照上传图片
- 检测标注图（优先 `inline` 返回的 base64，规避云托管多实例磁盘不共享导致的 404）
- 四项统计：检测数量、平均置信度、推理耗时、最高置信度
- 类别分布条形图、检测明细列表
- 模型状态条（真实推理 / 通用模型提示）

## 本地访问（已就绪）

后端当前已在你本机运行，直接浏览器打开：

```
http://127.0.0.1:8000/
```

> 若服务已停，重新启动：
> ```bash
> cd server
> ../.venv/Scripts/python app.py      # 或你自己的虚拟环境
> ```
> 开发调试时若用手机访问，把 `127.0.0.1` 换成电脑局域网 IP，并确保后端监听 `0.0.0.0`。

## 部署到云托管 = 一个正式网站

后端做成 Docker 镜像（见 `README-云托管部署.md`）推到微信云托管后：

1. 容器自动获得 HTTPS 域名；
2. **绑定你已备案的自定义域名**（如 `detect.example.com`）；
3. 浏览器访问 `https://detect.example.com/` 即网站，`/api/health`、`/api/detect` 等接口同域名可用；
4. 网站静态文件已随 `COPY . .` 烤进镜像（`server/web/index.html`），无需额外托管。

前端请求 `/api/detect` 时始终附带 `inline=true`，后端直接返回 base64 标注图——**无论单实例还是多实例都不存在结果图跨实例 404 的问题**。

## 文件位置

| 文件 | 作用 |
|---|---|
| `server/web/index.html` | 网站单文件（纯 HTML/CSS/JS，无外部 CDN 依赖） |
| `server/app.py` | `/` 与 `/demo` 路由返回该页面；`/api/detect` 支持 `inline` 参数返回 base64 |

## 想换成自己的域名 / 静态托管

- **最简单**：直接部署后端到云托管（如上），网站自然随容器提供。
- **纯静态托管**：把 `server/web/index.html` 单独丢到任意静态托管（对象存储 / Vercel / GitHub Pages），但需把前端里的 `/api/...` 改成你后端 HTTPS 域名（当前写的是同源相对路径，前端代码中 `fetch('/api/detect')` 改为 `fetch('https://你的后端域名/api/detect')` 即可）。
