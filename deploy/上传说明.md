# 上传说明 · 苹果检测识别 网页版

本目录就是要上传到 `https://liubojun.52byte.com/` 的内容。

## 文件清单

| 文件 | 说明 |
|---|---|
| `index.html` | 网页本体（单文件、零外部依赖），直接上传这一个即可 |
| `上传说明.md` | 本说明（可不上传） |

> 52byte.com 是**纯静态托管**，跑不了 Python/PyTorch 后端。所以网页只负责「选图 + 展示」，
> 真正的推理由后端完成（部署在微信云托管 / 你的服务器上，得到独立 HTTPS 域名）。

## 三步上线

### 1. 先填后端域名（必须）
用任意编辑器打开 `index.html`，找到文件**最上方**这段：

```js
const API_BASE = ""
```

改成你的后端 HTTPS 域名（云托管拿到的服务地址，形如 `https://apple-xxxx.run.tcloudbase.com`）：

```js
const API_BASE = "https://apple-xxxx.run.tcloudbase.com"
```

- 后端需开启 CORS（本项目后端已默认 `allow_origins=*`，浏览器跨域调用没问题）
- 如果网页和后端**同一域名**（比如整套都部署在云托管），这里留空 `""` 即可

### 2. 上传到 52byte.com
把 `index.html` 这一个文件传到 `liubojun.52byte.com`（覆盖现有页面）。
具体上传方式以 52byte.com 后台为准（文件管理 / FTP / 控制台拖拽）。

### 3. 验证
浏览器打开 `https://liubojun.52byte.com/`
- 顶部状态条显示「模型已加载 · 真实推理」 → 后端已连上
- 上传一张苹果照片 → 点「开始检测」→ 出现标注框 + 统计数据 ✅
- 若顶部显示黄色「未配置后端地址」→ 回去第 1 步把 `API_BASE` 填上

## 常见问题

- **状态条红色「服务未连接」**：后端域名填错 / 后端未启动 / 后端域名未配 CORS。确认 `API_BASE` 拼写，并确认后端 `/api/health` 可访问。
- **能连上但检测不出苹果**：当前权重是 COCO 预训练 yolov5s（含 apple 类），单果特写置信度偏低。把你的苹果专用 `best.pt` 覆盖后端 `server/weights/best.pt` 重新构建镜像即可。
- **网页版和小程序有区别吗**：无，共用同一套后端接口 `/api/detect`。

## 后端怎么来（简要）
1. 微信开发者工具 → 云开发 → 云托管 → 新建服务 → 用 `server/Dockerfile` 构建镜像（约 1.5–2GB）
2. 拿到服务地址 `https://apple-xxxx.run.tcloudbase.com` → 填进上面的 `API_BASE`
3. 网页版是浏览器直连，**不受微信"合法域名"限制**，云托管默认公网域名即可用，无需备案

详细步骤见项目根目录 `README-绑定52byte.md` 与 `README-云托管部署.md`。
