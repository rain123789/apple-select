# 苹果检测 · 本地直接运行版（纯前端 · 零后端）

把整个 `frontend-only/` 文件夹留在你电脑上即可，**不依赖微信、不依赖任何服务器、图片也不离机**——模型在浏览器本地用 ONNX Runtime Web 跑。

## 一、怎么运行（双击即可）
直接双击本文件夹里的 **`本地运行.bat`**：
- 它会自动启动本地服务，并用默认浏览器打开 `http://localhost:8080/`
- 若 8080 被占用，会自动顺延到 8081 / 8082 …，具体地址看黑色窗口顶部提示

> 依赖：脚本里写死了本机已有的托管 Python 路径
> `C:\Users\liubojun\.workbuddy\binaries\python\versions\3.13.12\python.exe`
> 只要这个 Python 还在，双击就能跑。换电脑时改一下 `.bat` 里的路径，或自行安装 Python 3.10+ 后把命令换成 `python serve.py` 即可。

## 二、手动运行（可选）
在本文件夹打开命令行，执行：
```
python serve.py
```
然后浏览器访问窗口里打印的地址。

## 三、怎么用
1. 浏览器打开后，顶部状态变成「模型已加载 · 浏览器本地推理」（首次要下载约 28MB 模型，稍慢几秒）
2. 点「选择图片」选一张苹果照片 → 点「开始检测」
3. 画面会框出 **apple**（COCO 模型共 80 类，也会一起识别人/瓶子等，属正常）

## 四、停止服务
关闭 `本地运行.bat` 的黑色窗口，或在窗口里按 `Ctrl+C`。

## 五、文件夹内容
- `index.html` — 检测页面（已改为自托管推理引擎，无外网 CDN 依赖）
- `yolov5s.onnx` — YOLOv5s COCO 官方权重（apple = 第 47 类）
- `onnxruntime-web/` — 浏览器端推理引擎（自托管，约 35MB）
- `serve.py` — 零依赖本地静态服务器（显式设好 .wasm/.mjs 的 MIME，否则浏览器拒绝执行模块）
- `本地运行.bat` — 一键启动脚本

## 六、排错
- 页面提示「推理引擎(ort)加载失败」：检查 `onnxruntime-web/ort.min.js` 是否和 `index.html` 同目录。
- 控制台报 `Failed to fetch ... .mjs` 或 MIME 相关错误：说明用了别的服务器（如旧版 `python -m http.server`）。请用本文件夹的 `serve.py`，它已正确设置 `.mjs = text/javascript`。
- 模型加载慢：首次需下载约 28MB 模型，耐心等几秒；之后浏览器会缓存。
