# 上传说明 · 苹果检测识别（纯前端 / 无后端）

本目录就是**不需要任何后端服务器**的网页版，模型在浏览器里本地跑，图片不会上传到任何服务器。

## 文件清单

| 文件 | 说明 |
|---|---|
| `index.html` | 网页本体（单文件，仅依赖 CDN 上的推理引擎 onnxruntime-web） |
| `yolov5s.onnx` | COCO 预训练模型（29MB，含 apple 第 47 类），与网页同目录会自动加载 |
| `上传说明.md` | 本说明（可不上传） |

## 两个版本，任选其一上传

### 版本 A：完整版（推荐，推理最快、完全离线）
把 `index.html` **和** `yolov5s.onnx` 一起传到 `liubojun.52byte.com`（同目录）。
浏览器直接读本地 `./yolov5s.onnx`，无需联网拉模型。

### 版本 B：极简版（只传一个 index.html）
若你的空间限制单文件 / 单文件大小，只传 `index.html` 也行：
- 页面默认先找本地 `./yolov5s.onnx`，找不到会**自动回退到官方 CDN** 模型
  `https://github.com/ultralytics/yolov5/releases/download/v7.0/yolov5s.onnx`
- 模型从 CDN 下载（约 29MB，首次稍慢），其余推理仍在本地

> 想强制只用 CDN、不依赖本地文件：打开 `index.html`，把 `const MODEL_URL = "./yolov5s.onnx"`
> 改成上面那条官方地址即可。

## 上传到 52byte.com
把文件传到 `liubojun.52byte.com`（覆盖现有扫雷页）。具体上传方式以 52byte.com 后台为准。

## 验证
浏览器打开 `https://liubojun.52byte.com/`：
1. 顶部状态条显示「模型已加载 · 浏览器本地推理」→ 模型就绪
2. 上传一张苹果照片 → 点「开始检测」→ 出现标注框 + 统计（检测数量 / 平均置信度 / 推理耗时 / 最高置信度）
3. 类别分布 + 检测明细也会列出（COCO 模型会同时识别人、瓶子等 80 类，apple 是第 47 类）

## 技术说明
- 推理引擎：`onnxruntime-web`（WASM，纯浏览器，无需显卡）
- 模型：YOLOv5s COCO 预训练（官方权重，原仓库不含苹果专用权重）
- 解码：`xywh → xyxy` + 置信度 `obj×类别概率` + 每类 NMS(IoU 0.45)，阈值 0.20
- 输入：letterbox 缩放到 640×640，归一化 `/255`，RGB→CHW
- 性能：普通笔记本/手机 CPU 上单张约几百毫秒（WASM）

## 换成你自己的苹果专用模型
1. 用你训练的 `best.pt` 导出 ONNX（本项目已验证的导出方式见 `README-云托管部署.md` 或本地 `server/detector.py` 注释）
2. 把导出的 `yolov5s.onnx` 覆盖本目录的文件，重新上传
3. 类别名由权重自带（若是单类苹果模型，类别数会变，页面 `COCO` 数组按需改即可）

## 常见问题
- **状态条红色「模型加载失败」**：网络无法访问 CDN（推理引擎或模型）。确认能联网；若空间屏蔽外链，用版本 A 把模型一起传。
- **检测不出苹果**：COCO 预训练对单果特写置信度可能偏低（约 0.38），已用 0.20 阈值兜住；换你自己的苹果专用 `best.pt` 导出即可显著提升。
- **推理慢**：WASM CPU 推理，手机上约 0.5–1.5s/张，属正常。
